# The Anatomy of a Blockbuster

## COMP3020 Social Web Analytics

This project analyses 500 English-language films released
between 2015 and 2024 using data from The Movie Database (TMDb).

## Research Areas

1. Text and content analysis
2. Hypothesis testing of horror and comedy ratings
3. Clustering of movie descriptions
4. Actor collaboration network analysis

## Data

- movies.csv: Movie information and descriptions
- cast.csv: Actor–movie relationships

## Tools

R and RStudio

## Reproducibility

The repository contains the datasets, R scripts and
visualisations used in the analysis.

Run the scripts using the supplied CSV files.
